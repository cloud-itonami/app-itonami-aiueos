# app-itonami-aiueos

The deployable shell of **aiueos** as an Itonami dapp: the session app (`apps/session`), the distributions (`distributions/aiueos`, `distributions/awai`), the computer example with its backing container (`examples/computer`) and the maintainer profile (`hermes/`).

The components of aiueos (the OS tree, the sources, the resources, the tests, the qualification suite and the documentation) are the library `kotoba.aiueos` in [kotoba-lang/kotoba](https://github.com/kotoba-lang/kotoba) under `lib/kotoba.aiueos`. This dapp is not usable on its own; it needs that library and an operator.

Source: kotoba-lang/aiueos at `6e5cd791fd97fdcd269c24a069ca053b2bfacdc9` (archived; its history is the history of these files). Split on 2026-10-26 by owner decision: a core product is core only as a library; as an app it is an Itonami dapp.
